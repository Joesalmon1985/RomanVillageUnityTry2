# Balance F1 as the default (20 Nov 2026)

Applies decisions 1, 2 and 10 of `DECISIONS_2026-11-20.md`. Branch `godboard/balance-f1`. Sim, tests and docs only; nothing under `Assets/World/Game`.

## What changed
- `PlagueState.InfectEvery` (saved, per game). New god board games get `PlagueRules.DefaultInfectEvery` = 3. `GodBoardModule.OnRoundEnded` draws infection cards when `round % InfectEvery == 0`. The global static `PlagueRules.InfectEvery` is gone; the study sets the saved field instead.
- `WarModule.InitState` sets `WarState.TiedLeadersFight = NeverWhenTied` (WA-11: tied leaders never fight; a lead of 2 still starts a war). Win stays at 10 points.
- Save version 8 to 9 (`SaveCodec.CurrentVersion`, step `V8ToV9`): a version 8 file has no `InfectEvery` and keeps 1 (the old behaviour: draw every round); its saved tie rule is kept. Legacy games have no plague or war and are untouched. Round-trip and migration test: `Save_BalanceF1_InfectEveryRoundTrips_AndAVersion8SaveKeepsTheOldBalance`.
- Tests that hard-coded the old defaults: `GodBoardJoinTests` (tie rule, default), `GodBoardWiringTests` (infection round count now `(round - 1) / InfectEvery`; the mid-plague save test sets `InfectEvery = 1` to get deep into the plague), `WarTests` (the tied-leaders test sets the old rule; new test for the default), `ApiSurfaceTests` and `SaveTests` (version 9), `GodBoardVirtualProof.Knobs` (Default is F1; `Knobs.BeforeF1()` is the study baseline), `GodBoardJoinProof` (new variant row "Before balance F1").
- `HistoricProof`: see Findings.
- Docs: `PRD_GODBOARD.md` PL-5, WA-11, 12.2 note; `G1-3-proof.md`, `G0-3-proof.md`, `G4-2-proof.md` regenerated; "After F1" section appended to `G1-3-tuning.md` (the study test no longer rewrites that file).
