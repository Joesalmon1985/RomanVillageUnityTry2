## Rule decisions (check against the owner's intent)
- Node ids are 1-based; arrays are indexed id - 1. Elements 0 Earth, 1 Fire, 2 Water, 3 Air (same order as `Campaign.Element`).
- Demons carry a kind: `KindCount[(id-1)*4+kind]`, because a spread demon keeps its source's kind (PL-8). `Demons[id-1]` is the total (cap 3).
- A cured kind is never placed anywhere (draw, epidemic, spread) and so never overflows or chains. The card is still discarded.
- Strengthened: a draw of that kind places 2 demons; cure clears it; strengthen is refused for a cured kind. Epidemic still places 3.
- Grace: `InfectRound` always draws (rate track from the start); `Epidemic` does nothing until `Rounds >= GraceRounds` (6) and returns false.
- Outbreak chain is breadth first in node-id order; the source stays at 3; a neighbour already outbroken in the chain gets nothing; stops when the 8th outbreak sets `IslandFell`.
- Empty deck: refilled from the shuffled discards (or all 48 if both empty).
- `Banish{Node, Kind=-1}`: one demon, cooldown 300 ticks single shared cooldown (`BanishReadyTick`). The legacy `World.Sim.Demons.Banish` is untouched (different namespace and type); player proximity to the node is for the caller to check.
- No per-tick system: the future turn engine calls `InfectRound` once per round (after the last people's turn) and `Epidemic` on each 7.
